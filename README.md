Система управления бронированиями для ресторанов на Django REST Framework.
REST API для управления рестораном: бронирования, столы, залы, меню, заказы, предзаказы, персонал и пользователи.

Технологии:

Python 3.13,
Django 6.0.4,
Django REST Framework,
PostgreSQL,
Redis,
Celery,
JWT Authentication,
Docker и Docker Compose,
ReDoc.

Возможности:

Регистрация и авторизация пользователей,
JWT-аутентификация,
управление залами и столами,
создание и управление бронированиями,
управление меню,
заказы и предзаказы,
генерация QR-кодов,
ReDoc API Documentation.

Установка:
git clone <repository_url>,
cd resto-reverse-backend

Создать файл .env и заполнить необходимые переменные окружения.

Запуск через Docker:

docker compose up --build

Документация API:
ReDoc:

http://localhost:8000/redoc/
